# МегаФон ВАТС → Service2

Service2 принимает REST-события Виртуальной АТС МегаФона через защищённый webhook и сохраняет завершённые звонки в разделе **Коммуникации → Звонки**.

## Подключение

1. В Service2 откройте **Коммуникации → Каналы связи**.
2. Создайте или откройте линию МегаФона.
3. Нажмите **Подключить ВАТС**.
4. Service2 один раз покажет:
   - HTTPS URL обработчика;
   - CRM-ключ.
5. В кабинете ВАТС укажите этот URL как адрес интеграции CRM и CRM-ключ как `crm_token`.
6. Выполните тестовый входящий и исходящий звонок.
7. Проверьте:
   - время последнего события на карточке линии;
   - появление звонков во вкладке **Звонки**;
   - доступность записи разговора.

Повторное нажатие **Переподключить ВАТС** ротирует CRM-ключ. Старый ключ перестаёт работать немедленно.

## Что сохраняется

ВАТС отправляет webhook как `application/x-www-form-urlencoded`; Service2 также принимает JSON для тестов и совместимости.

Для команды `event` поддерживаются типы `INCOMING`, `ACCEPTED`, `COMPLETED`, `CANCELLED`, `OUTGOING`, `TRANSFERRED`. Для диагностики сохраняются `user`, `ext`, направление и номер клиента.

Для команды `history` Service2 принимает:
- `callid` — внешний идентификатор звонка;
- `type` — `in` / `out`;
- `user`, `ext` — данные сотрудника ВАТС;
- `phone` — номер клиента;
- `start` — начало звонка;
- `duration` — длительность в секундах;
- `status` — результат (`Success`, `Busy`, `Missed`, `NotAvailable`, `NotAllowed` и другие значения провайдера);
- `link` — HTTPS-ссылка на запись;
- `crm_token` — ключ авторизации.

Повторная доставка того же `callid` обновляет существующий звонок и не создаёт дубль.

Если `start` приходит без часового пояса (например, `2026-10-03 16:00:00`), Service2 трактует его в `COMMUNICATION_TIME_ZONE`. По умолчанию используется часовой пояс финансового контура (`Asia/Barnaul` для текущего production). Значения с суффиксом `Z` трактуются как UTC.

## Безопасность

- CRM-ключ хранится только как парольный хеш.
- Webhook принимает только активную линию и активное подключение организации.
- Записи открываются пользователю только через существующие права Service2.
- Для редиректа на запись используется allowlist HTTPS-хостов.
- Хосты `megapbx.ru` из валидных ссылок записи добавляются в allowlist автоматически.
- Запросы ограничены по частоте и размеру.

## Ограничения первой версии

Сопоставление клиента выполняется по нормализованному номеру телефона.
Сопоставление сотрудника выполняется по имени/идентификатору пользователя ВАТС с username, ФИО или email пользователя Service2. Если ВАТС отдаёт другой идентификатор, звонок всё равно сохраняется, но сотрудник может остаться пустым — тогда нужно добавить явное сопоставление.
