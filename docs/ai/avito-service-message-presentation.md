# Отображение служебных сообщений услуг Авито

Применяется только к подключению 4 / аккаунту 446312402. Сохранённый отчёт,
его исходные counts, типы, коды, безопасные тексты и CSV не переписываются.
GET строит отдельную модель отображения без запросов Авито и записей в БД.

Служебное уведомление — только warning 1218 с семантическим подтверждением
состоявшейся безусловной привязки существующего объявления и без требования
исправить данные. Используется существующая семантика исходного текста,
сохранённая до redaction; видимое противоречие исключает понижение.
Один код 1218, условная/будущая или неудачная привязка не являются доказательством.
Любой другой warning, error/alarm и смешанное проблемное сообщение остаются
в «Требуют внимания». Общие события warning загрузки не понижаются.

Служебные уведомления считаются по сообщениям, остальные счётчики — по
объявлениям с соответствующим уровнем. Они могут пересекаться.
3002 типа info сохраняется информацией. Исходный уровень warning 1218 виден
в подробностях каждого сообщения и в CSV. Контакты, URL и секреты по-прежнему
скрывает существующий нормализатор; HTML экранируется шаблоном.
Полнота/завершение отчёта и подтверждение конкретной версии фида этим
отображением не меняются.
