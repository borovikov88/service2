# Фотографии услуг Авито

Новые файлы и фото по ссылке добавляются в существующем редакторе. Обложка —
первая ссылка ImageUrls; порядок сохраняется с обычным черновиком/историей.
До новой публикации доступны только авторизованные превью. Не более 10 фото;
прежний опубликованный файл сохраняет договорённую совместимость.

Pillow уже входит в зависимости. Декодируются только обычные JPEG/PNG/WebP,
до 8 МБ, 20 MP и 10000 px по каждой стороне. Изображение пересохраняется
в JPEG без исходных EXIF/GPS/скриптов/имени файла. Прозрачность заменяется белым
фоном. UUID URL не раскрывает серверный путь; все операции проверяют
connection/account/organization и текущие права управления каналом.

AvitoImageStorage использует отдельный private_avito_media рядом с checkout,
файлы0600/каталоги0700. AVITO_SERVICES_MEDIA_ROOT может переопределить путь
только вне BASE_DIR; он должен оставаться вне document roots всех сайтов.
Существующее PRIVATE_MEDIA_ROOT CRM не меняется. MEDIA_URL не выдаёт эти файлы.
Публичная выдача возможна только после локальной публикации файла внутри той же
транзакции; это не подтверждение загрузки фото Авито. Старые опубликованные
фотографии остаются доступны неизменяемым старым XML-версиям, пока подключение,
привязка аккаунта и источник включены.

Ссылки: HTTP80/HTTPS443, без userinfo/фрагментов; все DNS-ответы должны быть
публичными unicast адресами, числовой IP закрепляется при socket.connect.
Для TLS сохраняются проверка сертификата и исходный SNI. Перенаправления не
переходятся. Общий deadline прерывает socket даже при медленных HTTP-заголовках,
chunk headers и теле; read1, лимит8МБ и декодирование проверяют фактические данные.
Прямые ссылки Service2 принимаются только как точный канонический URL своего
asset, без query/кодирования/смены origin; чужой asset не уходит в сетевой fallback.

Перед публикацией проверяется весь новый активный снимок. Для внешних URL
успешная проверка действует15минут; cache связан с аккаунтом/организацией,
содержит только SHA256URL и сведения проверки, не полные URL. Бюджет30сек/32МБ
на попытку; успешные проверки сохраняются, чтобы повтор продолжал оставшиеся
ссылки. Долгий/недоступный источник не превращается в успешную публикацию.
Свои загрузки проверяются локально, не по анонимному HTTP до публикации.
Изменение внешнего изображения после проверки и фактическое получение/обработка
Авито требуют отдельного подтверждения; текущий item API не возвращает байты фото.

Для проверки именно Passenger UID защищённый оператор может вызвать
make_storage_probe_token(connection,actor), затем POSTJSONtoken в отдельный
avito_services_media_probe endpoint. Подпись Django с salt avito-media-probe
живёт120сек, связана с connection4/account446312402/org/channel/конкретным
активным actor и текущими credentials, требует установленного setupmarker.
Это не общий вход в загрузчик: нет пользовательских файлов/путей/URL или
создания assetrows, только фиксированная8x8синтетическая картинка с очисткой.
Ответ — пять bool; токен не печатается, не хранится и не передаётся в query.
SSH оператор не создаёт0700каталог под своим UID до подтверждения веб-процесса.
