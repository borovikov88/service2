# Актуальные и незавершённые задачи

Этот список отражает проверяемые пробелы текущего кода и вопросы старого отчёта,
а не содержимое недоступного внешнего issue tracker.

## P0 — доступ и достоверность

- **OPS-003: Завершить сверку файлов production.** В сессии владельца все 21
  dirty/untracked файла `public_static` совпали с исходниками. Preflight должен
  проверять такие результаты сборки отдельно от настоящих местных изменений.
  Владелец перенёс `backups/` вне checkout в приватный домашний каталог и
  подтвердил её отсутствие в последующем `git status`. SSH/HTTPS и передача
  secrets подтверждены Actions run `33967180783` после исправления ключа.
  Полный deploy preflight остаётся отдельной проверкой.

- **OPS-001: Выполнить первый сквозной прогон автоматизации.** Настроить
  отдельную reviewer identity, branch rules/auto-merge и production SSH secrets;
  подтвердить PR event/check, GitHub APPROVED актуального head, auto-merge,
  hosting preflight, deployment и health. До этого цепочка подготовлена только
  кодом.
- **OPS-002: Проверить прямой GitHub-side reviewer.** `development-codex.yml`
  по-прежнему запускается из карточки `DevelopmentTask`; сообщение чата не
  создаёт её автоматически. Для прямых PR добавляется `direct-pr-review.yml`
  с отдельными AI reviewer и bot publisher. Требуются внешний успешный вызов
  модели, актуальный GitHub review и повторная проверка после нового commit.
  Автоматический возврат замечаний разработчику вне активной сессии и auto-merge
  прямых PR ещё не подключены; настройка токена этого не заменяет.

- **AI-001: Проверить доступ из целевой среды.** Установить поддерживаемый способ
  подключения отдельного финансового советника в Codex и подтвердить его
  фактическим внешним вызовом. Локальный MCP-тест таким доказательством не
  является; ChatGPT вместо Codex не выбран.
- **AI-002: Опубликовать и вызвать connection probe.** Локально готов один
  нефинансовый tool. GitHub-публикация и SSH из Actions уже доступны, но
  deployment probe, его включение и вызов из целевой среды Codex не выполнены.
- **AI-003: Проверить полноту рабочих данных.** Отдельно проверить валовую
  прибыль, ДДС, ФОТ, организации/подразделения и последние активные импорты. Не
  подменять отсутствующие значения тестовыми числами или нулями.

## P1 — только после успешного вызова probe

- **AI-004: Реализовать scoped service token и три GET-only advisor tools.** Они
  поддерживают явный набор организаций, результаты по каждой организации, свод,
  active versions, свежесть, показатели ДДС и `null` для отсутствующих данных.
- **AI-005: Доказать отсутствие записи.** Тесты должны проверять все разрешённые
  организации и чужой ID, дубли scope principal–organization, неполную себестоимость,
  отсутствующий ФОТ и отсутствие новых import/sync runs или финансовых UPDATE.

## Требуют сначала фактической проверки, а не немедленной правки

- пропажа августа 2026 в ФОТ;
- дубли похожих документов;
- отрицательная/аномальная себестоимость;
- расхождение себестоимости с заказом клиента;
- продажи по менеджерам и прогноз зимы;
- применённость migration `0099` и refresh/apply на production.

## Не входило в эту передачу

В эту проверку не входят бизнес-правки, импорт из 1С, миграции или изменения
рабочей базы, deployment и изменение существующей permission model. Дословный
перенос всех старых сообщений также не выполнялся.
