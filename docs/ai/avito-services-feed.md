# Источник объявлений услуг

`/avito/<connection_id>/services-feed/` доступен только пользователям с
`can_manage_channels` в организации выбранного активного подключения Авито.
Импорт принимает обратный экспорт XLSX, включая вручную созданные объявления.
Имя файла начинается с ID аккаунта. Это удобная проверка, не доказательство
принадлежности: перед публикацией сервер проверяет аккаунт по ключам, полный
список активных объявлений и существующие autoload_item_id через API Авито.

Сохраняются поля категорий, Id, AvitoId, прайс-листы и ссылки на изображения.
Редактор изменяет только Title, Description и ImageUrls. Повторный импорт
сохраняет Id для уже известных AvitoId; состав объявлений можно обновить свежим экспортом. Поддерживаются до 200 активных
объявлений услуг; смешанные аккаунты и частичная выгрузка не публикуются.
Все строки экспортируются как Excel strings, без исполнения формул.
Исходные файлы не сохраняются в MEDIA_ROOT или Git; данные находятся в БД.

Черновик и опубликованный снимок раздельны. Кнопка публикации явно делает
проверенный снимок доступным через случайный UUID URL. Сохранение черновика
не меняет этот снимок. Ссылку нельзя публиковать в логах или аналитике.
URL содержит сведения объявлений и должен передаваться только Авито.
Смена аккаунта/организации, деактивация канала/подключения или отключение
источника блокируют выдачу. Не выдаём пустой фид для отключённого источника.
Оптимистическая версия защищает от потерянных изменений.

## Подключение

1. Импортировать свежую полную обратную выгрузку нужного аккаунта.
2. Проверить/отредактировать тексты и ссылки на фото, скачать черновик.
3. Опубликовать проверенную версию. Если URL уже подключён к Авито,
   опубликованные правки попадут в очередную обработку по расписанию.
4. Добавить URL файла XLSX в настройках автозагрузки именно этого аккаунта.
   Эта версия не меняет профиль Авито и не вызывает POST /autoload/v1/upload.
   Доступность автозагрузки и приём XLSX по URL должны быть проверены в кабинете
   конкретного аккаунта перед эксплуатацией. Публикация источника в Service2
   сама по себе не означает подключение или успешный импорт на стороне Авито.
5. Проверить отчёт автозагрузки v4 и сохранение существующих AvitoId.

Формат XLSX выбран для сохранения сложных параметров категорий из официального
экспорта, включая PriceList. Конвертация в XML без проверенной схемы категории
не выполняется. Фото задаются URL, сервер не скачивает произвольные ресурсы.
Встроенная загрузка файлов фотографий и создание новых объявлений не входят
в текущую реализацию.

Проверки: `python manage.py test pool_service.tests.test_avito_services_feed
--settings=service_site.test_settings`, check и makemigrations --check.
