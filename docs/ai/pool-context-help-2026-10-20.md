# Компактные подсказки калькулятора

База: main после PR341, `0bb75a435928f602117bd39a67df52df2066d6e4`.

Справочные тексты в параметрах, редакторе строки, таблицах сметы и каталоге перенесены в кнопки «?». Пояснения расчётного/сметного количества, округления, исходной цены и наценки объединены в одну подсказку в ячейке цены. Между фрагментами есть пробелы и разделённые абзацы. Единицы, режим «авто/вручную», суммы, модели и основные статусы остаются видимыми.

Проверки сметы, несовместимости строк и предупреждения кандидатов каталога имеют заметный индикатор «!». Подробности и доступные действия исправления открываются в поповере. Ошибки ввода и сообщения текущей операции не скрываются. Контекст подтверждения действий — например, какую строку заменяют — также остаётся видимым.

Поповер открывается по наведению/фокусу и по нажатию; закрывается нажатием снаружи, Escape или кнопкой закрытия. Клавиатурой можно перейти внутрь и вернуться к триггеру. Используется верхний слой браузера, ограничение размерами экрана и прокрутка длинного содержимого. Для модальных окон поповер находится внутри их области фокуса. Есть тёмная тема и увеличенные сенсорные кнопки.

Исходные DOM-узлы с ID сохраняются скрытыми, поэтому обновления строк и подсказок продолжают работать. Перерисовка вариантов и повторный поиск каталога обновляют подсказки; устаревшие триггеры удаляются. Дублируемые ID не попадают в содержимое поповера. HTML берётся только из уже подготовленных/экранированных узлов интерфейса.

Проверки:

- 18 Node-тестов чисел/состояния/параметров — PASS.
- 3 Django-теста текста/числового отображения — PASS.
- `tools/estimate-browser/help.cjs`: desktop и мобильный 390px, тёмная тема, hover/focus/tap, Escape/наружное закрытие, клавиатура, модальное окно, границы экрана, добавленная строка, смена КП, несовместимый кандидат и повторный поиск — PASS, 0 JS errors.
- Высота строки материала меньше 180px в тестовой конфигурации; открытие поповера не меняет её. Открытие справки не вызывает API-запросов.
- Основная Chromium-регрессия и `numbers.cjs` — PASS, 0 JS errors. В тесте ручного нулевого количества уточнён фильтр ответа, чтобы не принять запоздалый ответ предыдущей проверки за новую операцию.
- Изменений сервисных формул, цен, правил округления, моделей/миграций и клиентского PDF-шаблона нет.

Браузерные проверки выполнены на локальных синтетических данных, production не изменялся. Проверялся Chromium; другие браузеры отдельно не тестировались. При поддержке Popover API используются компактные поповеры. Без методов API или поддержки селектора :popover-open остаётся исходная видимая справка: приложение продолжает работать без скрытия пояснений.

Поправка независимого ревью: проверка методов и селектора выполняется до добавления панели и скрытия источников. Браузерная регрессия отдельно отключает API и поддержку селектора (вызов неподдерживаемого matches принудительно бросает исключение); параметры, материалы, проверки и динамическая смена КП сохраняют доступную справку без ошибок JavaScript. Fallback намеренно оставляет развёрнутый текст вместо компактных кнопок.
