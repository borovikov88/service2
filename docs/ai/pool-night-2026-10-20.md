## Порядок строк

Кнопки ↑/↓ перемещают строку на одно видимое место в текущей таблице текущего
КП. На телефоне зона44px, клавиатура поддерживается обычными кнопками; drag
пока не добавлен, чтобы не перехватывать прокрутку и редактирование полей.
Массив rows уже является порядком хранения/печати: новая схема и миграции не
нужны. Меняются местами ссылки на видимые строки; скрытые слоты остаются на
месте. ID, связи с нагревателем, количества, цены и другие варианты сохраняются.
Новые автоматически добавляемые строки по прежним правилам идут в конец.

Проверки:21 Django (включая реальное save/load, пересчёт, печать),9 Node,
браузер390/1365 (touch/keyboard, server validate, итоги, изоляция КП).

## Покрытие подбора по текущему коду

- Насос/фильтр: есть строгий подбор по расходу, питанию и напору. Пробел:
  неизвестная рабочая точка/питание останавливают подбор вместе с реальным
  несоответствием; несколько насосов требуют схемы.
- Нагреватели: отдельный подбор каждого источника на полную мощность. Пробел:
  неизвестная мощность/питание не разделены с доказанным недостатком мощности.
- Закладные: роль, материал/профиль, отделка. Пробел: отсутствующие характеристики
  блокируют предложение так же, как несовместимая отделка или конфликт материала.
- Насос/клапан теплообменника: узкий набор подтверждённых моделей, отдельные
  присоединения, пределы температуры/Qmax/Hmax. Не заданное присоединение
  сейчас не даёт даже предварительного предложения.
- Регулятор/форсунка уровня: внешняя схема и подтверждённые пары; неизвестная
  гидравлика форсунки оставляет строку пустой. Конфликты должны оставаться запретом.
- Плёнка: подтверждённые серии и площади рулона. Неизвестную единицу продажи
  нельзя трактовать как м²: это изменило бы цену и итог без доказательства.
- В реально генерируемом расчёте без отдельного подбора: обеззараживание
  (treatment), обвязка/автоматика (piping), геотекстиль (finish_geotextile),
  штукатурный слой в м³ (tech_plaster_material). Для них требуется отдельная идентификация и состав/единица товара;
  совпадение слов само по себе недостаточно для безопасного внесения цены.

Это аудит кода, не статистика production-каталога. Рабочая выгрузка в этой среде
не доступна: предыдущий прямой запрос был403, не повторялся и не обходился.

## Вопросы на утро

- Для труб/обвязки: состав по проекту либо отдельные согласованные типовые наборы?
- Для обеззараживания: метод обработки, питание, схема управления/реагенты?
- Для материалов: подтверждённые единицы продажи и упаковки, особенно геотекстиль.
- Любой предварительный подбор требует проверки рабочей точки/схемы монтажа;
  предупреждение не является инженерным подтверждением совместимости.
