## Поддерживаемые XML param

Имена без учёта регистра, лишних пробелов и ё/е. Другие имена не угадываются.

| Поле | Поддерживаемые имена | Примеры значений |
|---|---|---|
| Корпус | Материал корпуса; Body material | ABS; пластик; нержавеющая сталь; AISI 304; AISI 316L |
| Сталь корпуса | Марка стали корпуса; Марка стали; Body steel grade | AISI 304; 316L |
| Отделка | Тип отделки; Тип покрытия бассейна; Отделка бассейна; Pool lining | пленка; лайнер; плитка; бетон; мозаика; пленка / плитка |
| Встроенный регулятор | Регулятор уровня в комплекте; Встроенный регулятор уровня; Built-in level regulator | да / нет; в комплекте / не входит в комплект; yes / no |
| Схема внешнего регулятора | Схема регулятора уровня; Level regulator scheme | внешний поплавковый через отдельную форсунку; external_float |
| Совместимость форсунки | Совместимые регуляторы уровня (артикулы); Compatible level regulator SKUs | 16791,528,32304 — только реально подтверждённые артикулы |

Общее поле «Марка стали» без подтверждения стального корпуса не превращает
товар в стальной. Явное поле «Марка стали корпуса» относится к корпусу и
конфликтует с ABS, если источники расходятся. «Материал винтов» и общее «Материал» не принимаются за корпус.
Пустое, неизвестное или противоречивое значение не становится «да» или «нет».
Конфликт с названием/документированным обогащением блокирует автоподбор;
известные дополнения Aquaviva/Kripsol сохраняются при отсутствии противоречия.
XML param должен действительно присутствовать в выгрузке: наличие характеристики
только в HTML карточке недостаточно.

## Правила подбора

Подбор запускается при создании, явном автоподборе и через API пересчёта
(а также при смене профиля закладных для одного КП). Открытие сохранённой
версии подбор не запускает. Сам чистый recalculate() не обращается к каталогу;
API вызывает auto_select() после него.
Полные подходящие пары предпочитаются перед ранжированием баков по цене.
Если подтверждённой форсунки нет, внешний бак предлагается предварительно,
форсунка не угадывается; предупреждение называет артикул регулятора и нужные поля.
Для форсунки обязательны доступность, материал/бренд профиля КП и отделка.
Совместимость может подтверждаться технически, без списка артикулов: назначение
отдельной сообщающейся линии, свободный проход и подтверждённые интерфейсы.
Два внутренних клеевых соединения одного диаметра в мм допускают общую трубу.
Разные диаметры/типы соединений требуют подтверждённой переходной обвязки;
резьбовые/наружные клеевые интерфейсы не объявляются автоматически совместимыми
по одному совпадению номинального диаметра. Список совместимых SKU —
альтернативное дополнительное свидетельство, не обязательный фильтр и не способ
обойти явную напорную схему, закрытый проход или противоречие характеристик. Допускаются возвратные и пылесосные закладные
при явном подтверждении совместимости, всегда отдельной строкой системы уровня.

Один вариант → все КП; два → дешёвый/дорогой/дорогой; три и более →
дешёвый/средний/дорогой среди технически подходящих. Не требуется AISI316 от
внешнего бака премиум; профиль применён к закладной в чаше.
Ручной регулятор, форсунка, цена, количество, блокировка и исключения защищены.
Встроенный регулятор исключает автоматическую пару; ручная пара не удаляется,
показывается предупреждение дублирования. Цена той же модели не обновляется
попутно с автоподбором. Сохранённая история не получает товар автоматически.

Для фактического включения живых форсунок нужно проверить их экспортируемые
данные: назначение отдельной линии, свободный проход, тип/диаметр присоединения,
материал и отделку; для регулятора — именно соединение с чашей, не вход водопровода.
Запрашивать обязательный список артикулов у владельца неверно: такого требования
в документации нет. Доступа к текущим XML param нет; нельзя обещать конкретную
живую форсунку без этих сведений. Неизвестные значения сопровождаются конкретным
предупреждением и не объявляются доказанной несовместимостью.
Три перечисленных бака начинают участвовать в предварительном подборе при
подтверждённой доступности и отсутствии конфликтов XML; их цены читаются из фида.

## Проверки

Синтетические XML проверяют корпус против винтов, разные источники/дубликаты,
отделку, неизвестное значение комплектации, сохранение старого enrichment,
1/2/3 ценовых уровня, выбор пары до цены, отсутствие неподтверждённой форсунки,
профиль/отделку, ручные правки, встроенную систему, историю, повторный расчёт.
Финансовый пример использует синтетические 4000/11000/13000 ₽ + форсунка 100 ₽:
дельты составляют 4100/11100/13100 ₽, без изменения возвратных форсунок/работ.

Проверено: 58 целевых Django tests PASS. Независимое ревью исправлений — без
блокеров; оба замечания (явная сталь корпуса против ABS, конфликтный ручной
регулятор) исправлены и покрыты регрессиями.

## Уточнение: техническое соединение вместо обязательного списка SKU

Новые XML param (в скобках английский alias):
- «Назначение линии уровня» (`Level line purpose`): «отдельная сообщающаяся линия» /
  `communicating`; «напорная линия фильтрации» / `filtration`.
- «Свободный проход линии уровня» (`Level line free passage`): да/нет, yes/no.
- «Тип подключения линии уровня» (`Level line connection type`):
  «клеевое внутреннее» / `glue_socket`, «клеевое наружное» / `glue_spigot`,
  «BSP внутренняя» / `bsp_female`, «BSP наружная» / `bsp_male`.
- «Диаметр подключения линии уровня» (`Level line diameter`): число с явной
  единицей, например `50 мм`, `50 mm`, `1.5 inch`. Голое `50`, `DN50`,
  неопределённая дробь без единицы не преобразуются в доказанный диаметр.

Отсутствующие сведения не придумываются. Противоречивые дубликаты и нераспознанные
значения сохраняются как conflict/unknown, а не как «нет». Модельные numerical
характеристики RO-7/RGP.C/3150 в этой доработке не добавлены.

Регрессионные примеры синтетические: техническая пара с Ø50 и двумя внутренними
клеевыми соединениями подбирается без SKU; существующие фильтрационные форсунки
не изменяются. Иной SKU в необязательном списке также не запрещает доказанное
техническое совпадение. Закрытый проход, напорная линия, разные диаметры/типы,
неизвестные единицы и противоречивые дубликаты не обходятся списком SKU.

Финальная проверка технического пути: 81 Django test PASS, system check PASS,
makemigrations --check --dry-run: No changes detected; независимое ревью —
без блокеров (19 целевых тестов повторены проверяющим). Синтетическая пара
100+100 ₽ добавляет ровно 200 ₽, повторный подбор не дублирует строки.

  При ручном выборе остаётся предупреждение с конкретным полем диаметра.
