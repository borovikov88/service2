# Прямой цикл задачи из Codex-чата

## Проверенный вход

Задача в текущем Codex-чате выполняется ведущим и отдельными субагентами в
выданной рабочей копии. Это не создаёт `DevelopmentTask` в production и не
запускает `development-codex.yml`: у чата нет подключённого service2 tool/API.

На 5 сентября 2026 года локальная ветка `work` содержит два последовательных
коммита `4bb4aa3` и `66fcfe5`. Последний добавляет
`development_delivery.py`, тесты delivery/preflight и связанные изменения.
Git remote и GitHub-сессия CLI отсутствуют, а HTTPS к GitHub отклоняется proxy
с CONNECT 403. Поэтому из shell нельзя прочитать актуальный `main`, head/base PR
№87, разрешить возможные конфликты или доказать обновление PR.

## Публикация текущей задачи

Для этой сессии единственный доступный канал публикации — действие интерфейса
Codex **Update PR** для уже связанного PR №87. Нельзя выбирать **Create PR**:
это создало бы запрещённый дубликат. Перед отправкой интерфейс должен показывать
именно PR №87. Нажатие выполняет внешний push, который невозможно имитировать
локальной командой без remote и credentials.

После Update PR сначала нужно внешне подтвердить, что PR №87 основан на
актуальном `main` после PR №86 и содержит commit `66fcfe5`, включая
`pool_service/services/development_delivery.py`. До такой проверки merge и
deployment запрещены.

## Незакрытое звено прямого цикла

Автоматическая независимая проверка и delivery сейчас реализованы только для
PR, связанного с `DevelopmentTask` и сохранённой `DevelopmentIteration` типа
`ai_review`. Прямой PR из Codex-чата таких записей не имеет. Локальный review
отдельного субагента не может сам опубликовать GitHub `APPROVED` и не должен
подменяться текстом `ACCEPT` в PR.

Следовательно, прямой путь Codex-chat → PR подтверждён только до публикации.
Автоматические independent approval, auto-merge и deployment для него
fail-closed заблокированы до появления поддерживаемого способа передать
исходную задачу, критерии и точный head отдельному reviewer. Новый ingress или
GitHub-side reviewer нельзя считать выбранным без проверки доступных средств
целевой среды.
