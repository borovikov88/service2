# Назначение теплового насоса

Отдельное исправление от main092562b. Родитель подтвердил на production,
что в прямой нагрев бассейна выбирался Aquaviva AVH18S для дома. Причина:
классификация объединяла все названия «тепловой насос», а подбор проверял
мощность и питание без проверки явно иного назначения.

Теперь явное назначение для отопления дома/здания запрещает автоматический
подбор в прямой бассейновый контур. Проверяются название, описание, категория
с родителями и URL. Общий раздел «Товары для дома», упоминание дома рядом
с бассейном, воздух–вода и слово «отопление» без объекта не служат запретом.
Обычные бассейновые модели остаются доступными.

Ручной поиск сохраняет товар с конкретным пояснением: применение через
отдельный теплообменник требует подтверждённой схемы. Саму такую схему
исправление не создаёт и совместимость не подтверждает. Ручные значения
не снимаются автоматически. Старые версии при загрузке сохраняют суммы,
но известное иное назначение из сохранённого названия/URL даёт предупреждение.
При явном повторном автоподборе неподходящий неизменённый автоматический
товар заменяется допустимым либо снимается с пояснением.

Добавлено optional JSON-поле heater_purpose_note; миграций БД нет.
Ключ кеша каталога повышен доv11, чтобы данные назначения из описания/родительской
категории появились сразу после обычной загрузки нового каталога.
Цены магазина, данные production и исправление Escape не менялись.

Синтетические проверки: замена100→300 меняет итог на+200; снятие строки
уменьшает его на100; ручные123,45×2=246,90 сохраняются с предупреждением.
Проверяются повторный подбор, JSON/evaluate/recalculate и HTML-печать.
Рабочий XML не запрашивался; live QA опубликованной версии выполняет родитель.

Проверки: все217 Django-тестов калькулятора PASS, включая6 новых тестов
назначения. Независимое ревью завершено без блокеров, diff-check чистый.
