# Освещение, связанные количества и состав строительства

Дополнение к локальной партии fix/estimate-two-stages, сохранённой на7bc6d129d65e62cfe8d249f752899a5c7fd312fd. Новая ветка fix/estimate-lighting-links, production не менялся.

Владелец уточнил: донный слив только для опорожнения, без всасывания насосом при купании. В текущей форме явно выбрана эта схема; при объёме до50м³ включительно предварительная комплектация1шт, выше —2шт. Для suction/unknown по-прежнему2шт. В старых версиях отсутствующая схема не восстанавливается автоматически. Ручные количества сохраняются. Порог объёма — правило комплектации владельца, не подтверждение безопасности всасывания. Источник различия: официальная инструкция Pentair StarGuard (https://www.pentair.com/content/dam/extranet/nam/pentair-pool/residential/white-goods/starguard/starguard-8-inch-main-drain-installation-guide-english.pdf), с3–4: опасность присасывания и отдельные защитные меры для одиночной всасывающей точки. Это техническая справка по изделию, не утверждение локальной нормативной применимости.

Фонтанное назначение в названии/описании/категории отклоняет автоматический подбор прожектора бассейна. Явные отрицания учитываются локально. Старый ручной выбор остаётся с предупреждением. Белый/RGB выбирается в параметрах; доказанное несовпадение цвета и противоречивые сведения исключаются из auto. Неизвестный цвет требует проверки, не превращается в подтверждённый.

RGB добавляет один контроллер: среди допустимых каталожных кандидатов дешёвый в эконом и дороже в остальных по общей логике ценовых уровней. Обычный RC-01 и Wi-Fi подтверждены карточками магазина, но электрическая/протокольная совместимость с конкретным прожектором не заявляется без данных. Цена берётся из текущего разрешённого каталожного источника, вручную в код не переносится. Карточки22окт: https://shop.aqualine22.ru/basseini/274-oborudovanie-dlya-bassejnov/279-osveschenie-dlya-bassejnov/pult-upravleniya-k-progektoram-aquaviva-rc-01.html (магазин7380), https://shop.aqualine22.ru/basseini/274-oborudovanie-dlya-bassejnov/279-osveschenie-dlya-bassejnov/pult-upravleniya-k-progektoram-aquaviva-rc-01-wi-fi.html (17663). При белом свете контроллер исключается обратимо. Повторные RGB/white/recalc/save/load не добавляют второй контроллер.

Трансформатор и контроллер отображаются в оборудовании. ПВХ закреплён в конце обеих соответствующих таблиц и в печати; перетаскивание не меняет это правило. Под названием — бренд и ссылка по каталожному артикулу; при отсутствии vendorCode честно показан ID. Полная модель не дублируется; для ручного короткого названия модель остаётся в названии. URL проверяется на HTTPS shop.aqualine22.ru, текст экранируется.

Монтаж закладных пересчитывается сервером по фактическим активным точкам после изменения скиммеров, форсунок и освещения. Автоматические ниши и коробки следуют количеству прожекторов; коробки суммируются и для нескольких моделей. Ниши разных моделей без явной связи не объявляются совместимыми. Нулевое количество прожекторов обнуляет автоматические количества комплектующих. Ручные значения не заменяются. Галка строительства исключает/восстанавливает оба исходных строительных блока атомарно, с выбором одного/всех КП, сохраняя индивидуальные исключения строк.
