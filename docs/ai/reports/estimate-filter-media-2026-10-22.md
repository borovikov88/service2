## Реализовано

В оборудовании — отдельная загрузка для каждого фильтра. Эконом/стандарт выбирают кварц, премиум — стекло. Указанные владельцем URL предпочтительны среди технически подходящих кандидатов с сопоставимой полнотой данных. Каталог категории «Кварцевый / стеклянный песок» показывает оба материала всех брендов из выгрузки, включая неподтверждённые варианты с предупреждением. Ручная замена не подменяется обратно при пересчёте.

Масса считывается только из явных характеристик загрузки фильтра (XML либо подписанные поля названия/описания). Масса корпуса, диаметр фильтра, производительность и общий размер бассейна не заменяют массу загрузки. Для стекла требуется масса стеклянной загрузки; коэффициент 0,8 не предполагается. Проверяются известная фракция, запреты материала, конфликты данных. Неподтверждённый кандидат допускается с «Проверить», но количество/стоимость без данных не выдумываются.

Количество мешков = ceil(масса загрузки × целое количество фильтров / масса мешка). Цена за кг, если явно указана, применяется к кг без деления на упаковку. Песок не получает строительный или отделочный запас. Связанный фильтр должен измеряться в штуках/комплектах. Отдельно сохраняются цена, фасовка и единица продажи: смена фасовки того же SKU не может смешаться со старой ценой. Явное обновление принимает новую пару; при ручном количестве изменение фасовки требует перевыбора/подтверждения.

Ручные цены (включая ноль и очистку), количества, выбор, исключения, удаление, порядок и сохранённые версии защищены. Новые расчёты и явный пересчёт копии получают маркер функции. Старые версии при чтении не дополняются. При наличии старой пользовательской строки песка автоматическое добавление второй стоимости не выполняется.

## Источники и ограничения

Владелец указал кварцевый товар https://shop.aqualine22.ru/basseini/aksessuary/prochie-aksessuary/kvarc-pesok.html и стеклянный https://shop.aqualine22.ru/pesok-steklyannyj-aquaviva-fraktsiya-05-15-mm.html. Вторая карточка прочитана: артикул12126, диапазон0,5–1,5мм, назначение для фильтров бассейнов. Масса мешка в доступном тексте отсутствует. Общая реклама экономии стекла «до20%» не доказывает точную норму выбранного фильтра. Другая карточка20кг SKU99947 не приравнивается к12126. Первая карточка через web не прочитана; её цену/фасовку не утверждаем и не фиксируем в коде. Загрузку XML после ранее полученного403 не повторяли/не обходили. Production выбирает по своей штатной выгрузке; её фактическое покрытие не объявлено проверенным локальными синтетическими тестами.

Схема многослойной засыпки и разрешённые фракции требуют паспорта конкретного фильтра. При неизвестной массе стекла/фасовке строка показывает «Уточнить», а не фиктивное количество. Ручное количество можно указать после проверки. Каталоговые цены не изменяются и не зашиваются в код.
