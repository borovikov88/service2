# Пустые блоки, добавление в одно/все КП и ставки ПВХ

Редактор полностью убирает пустые таблицы и пустой контейнер этапа. Клиентская печать также пропускает таблицы без позиций. Исключённые позиции остаются в прежнем разделе восстановления, а для добавления в ещё пустой блок есть общий выбор назначения под сметой. Подписи этапов сохраняют согласованное поведение: без строительства обе скрыты; при возврате строительной позиции возвращаются, если соответствующий этап содержит позиции. Данные строк не удаляются и суммы не меняются из-за отображения.

Новая строка любого типа сначала открывает выбор «только в этомКП / во всехтрёхКП / отмена». При отмене остаётся черновик редактора, строка ещё не добавлена. Для всехКП добавляются независимые копии со стабильным общимID; исходные данные других строк не меняются. Лимиты/конфликты проверяются до мутации, частичное добавление не допускается. Если исходный блок исключён, восстановится только новая строка, остальные строки сохранят исключение. Существующее редактирование работы и подтверждение её цены сохраняется; новая работа после выбора области проходит прежний серверный процесс подтверждения расценки.
