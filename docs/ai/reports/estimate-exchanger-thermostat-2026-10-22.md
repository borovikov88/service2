# Термостат теплообменника и панель с регулировкой температуры

Основа main3806ef88c3a6e2e64ecd4199e6584e3ed538d1f9. Владелец разрешил штатную публикацию после проверок.

Новая строка термостата создаётся в оборудовании для каждой строки теплообменника, количество следует количеству теплообменника при автоматическом режиме. Для электрического нагревателя и теплового насоса отдельно не создаётся. Эконом предпочитает указанный владельцем цифровой контроллер-термостат Aquaviva; стандарт/премиум выбирают по общей логике технической фильтрации и ценовых уровней. Один подходящий вариант одинаков во всехКП. Цены только из каталога, не из текста веб-страницы и не фиксированы в коде.

Одна активная подходящая панель с подтверждёнными regulation/exchanger и без запрета/конфликта датчика обратимо исключает автоматический отдельный термостат для одного теплообменника. При двух панелях, нескольких теплообменниках, неизвестной связи, несовместимой нагрузке панели или противоречивых данных автоматического исключения нет. Таймер/индикация температуры не равны регулированию. Известный AVP-01 распознаётся строго по модели/бренду или точному URL; AVP-010 не наследует функцию. Отрицания и XML-конфликты перекрывают позитивное предположение.

AVP-01 прямо указан владельцем как панель с регулированием. Найден первичный паспорт https://bas.ru/docs/av-avp_2647.pdf : обложка AVP-01, температурная уставка и управление теплообменником, датчик в комплекте. Внутри документа встречается обозначение AVO-01, поэтому полная электрическая схема/нагрузка по этому описанию не объявляются инженерно подтверждёнными. Карточка https://shop.aqualine22.ru/basseini/zapchasti/zapchasti-dlya-teploobmennikov-i-elektronagrevatelej/tsifrovoj-kontroller-termostat-aquaviva.html подтверждает назначение отдельного Aquaviva для бассейна/теплообменника; страница AVP через web недоступна, это не выдаётся за успешное чтение. XML после прежнего403 не запрашивался.

Ручные цены/количества, каталожные цены, исключения и удаление защищены. При ручном возврате строка остаётся с предупреждением о дублировании функции панели. Старая ручная строка «Термостат» типа other не вызывает второе начисление, просится проверка назначения/связи. Удалённая управляемая строка не восстанавливается пересчётом. Старая история не дополняется на evaluate/load/save; явный пересчёт редактируемой копии включает новый состав. Панель исключена→термостат возвращён со старой ценой; панель восстановлена→авто термостат исключён. Технические сведения могут обновляться при явном подборе без изменения замороженной цены панели.

Независимое предварительное ревью нашло2P2: несовместимый автоматический термостат оставался при отсутствии замен, а две панели считались одной. Оба случая исправлены и добавлены регрессии. Проверено сохранение ручного несовместимого товара с конкретным предупреждением, обновление отрицательных фактов ручной панели, отсутствие произвольного многоканального назначения. Контроль на синтетике: термостат100; панель500 заменяет его, дельта итогов+400, общие работы не добавляются.
