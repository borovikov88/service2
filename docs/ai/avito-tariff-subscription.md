# Подписка услуг Авито: контракт, доступ и независимые даты

Область: только Service2 №4 / Avito 446312402, категория services.
Товарное подключение №1 и ручной календарь не меняются.

## Проверенный публичный фрагмент

Источник: предоставленный владельцем экспорт swagger (3).json, раздел
Авито Promo; нужный фрагмент прочитан и подтверждён владельцем 26.10.2026.
В репозитории фиксируется этот публичный фрагмент, не весь экспорт и не
рабочие ответы. Официальный каталог: https://developers.avito.ru/api-catalog

Метод POST /api/1/agency/clients предназначен для client_credentials
учётной записи агентства. Точное тело первой страницы:

    {"limit":100,"offset":0,"extra":{"subscription":true}}

limit обязателен, 1–100; offset неотрицательный, начальное смещение 0.
Ответ 200: status="ok", result.clients — массив, result.total — число клиентов.
Обязательные поля клиента: clientId, name, status, linkType, linkTime.
Типы/перечисления неиспользуемых status/linkType/linkTime в переданном
фрагменте отдельно не зафиксированы: reader проверяет их присутствие,
не сохраняет значения и не использует их для вывода об активности подписки.

subscription дополнителен. В нём обязательны category, level, isActive:
category включает services, level — basic/extended/maximal/ultra,
isActive — Boolean. expiredTo необязателен; при наличии — RFC3339 date-time
с известным смещением или Z. Present null/пустая строка/naive datetime/дата
без времени не становятся отсутствующей датой. -00:00 означает неизвестное
смещение и не используется как подтверждённый момент. Нормальная API-дата
сохраняется отдельно со смещением; исходное тело ответа не сохраняется.

Этот агентский контракт не заменяет одноимённый контракт статистики
собственного профиля из swagger.json, раздел Объявления. X-AgencyClientId
от агентской статистики к списку клиентов не добавляется. Лимиты статистики
не переносятся на этот метод автоматически.

## Реальное чтение и проверка применимости

CONTRACT_STATUS=verified означает известный формат, не доказанные права.
Первая документированная read-only страница является ограниченной проверкой
доступа; status="ok" с корректным контейнером списка подтверждает доступ
к методу, но не подписку выбранного клиента. HTTP 403 означает отказ
доступа к методу, не доказанное отсутствие агентского статуса и не окончание
тарифа. 401/auth errors учитываются отдельно от method-level отказа.
Пустой полный список не означает inactive. isActive берётся только из
subscription точного clientId 446312402 с category=services.

Используются существующие OAuth, account identity, HTTP transport и DB throttle.
Новый фиксированный read-only POST запрещает redirect с credentials.
URL ограничен api.avito.ru; body/path не задаются клиентом.
Одна страница за вызов, отдельная консервативная пауза 60 секунд на этот метод.
Это внутренний безопасный бюджет, а не заявление об официальном rate limit.
Безопасный предел reader — три страницы / 300 клиентов. Превышение даёт
явный incomplete, не отсутствие клиента. Новых Cron и сборщиков нет.

Все страницы требуют стабильного total, точного offset/числа строк и
отсутствия повторов. Частичный результат не становится успешной подпиской.
Продолжение сохраняет только cursor/счётчики, нормализованную подписку
целевого клиента и private HMAC fingerprints идентификаторов для проверки
повторов. Они привязаны к текущему секретному stamp и source/org/channel,
не содержат names/status/linkfields/сырых других clientId и никогда не
выводятся в UI, receipt или логи. При смене binding старый progress скрыт.

## Надёжность и данные

HTTP находится между короткими reserve/commit транзакциями. Lease 90 секунд,
свежие права/actor/org/account/credentials проверяются до и после чтения;
истёкший или заменённый lease не может записать ответ. Параллельное чтение
не отправляет второй POST. При ошибке сохранённый успешный API-снимок и его
время остаются; новое имя периода/активность ему не приписываются.

expiredTo разбирается как aware RFC3339. API-значение, source и время получения
отделены от ручной даты/источника/времени подтверждения. Сравнение календарных
дат явно выполнено по времени Барнаула. Расхождение показывается обоими
значениями; ручная дата не перезаписывается, напоминания не перенастраиваются.
Устаревание — отдельный признак; дата или баланс не определяют isActive.
Доступ Messenger также не выводится из названия level.

setup_evidence(actor) только читает закрытые DB-метаданные, без уровня,
конкретной даты, списка клиентов или fingerprints. probe_once() предназначен
для уже существующего protected exact-main оператора: его per-binding
ledger резервируется до возможного HTTP. После 403/неопределённого ответа
новые deploy не повторяют probe; явный разрешённый UI refresh остаётся доступен.

Вопрос поддержке теперь касается применимости метода и официального
read-only способа для собственного аккаунта. Формат запроса больше не
называется неизвестным. Обращение самостоятельно не отправляется.

## Проверки

Синтетические regression/security tests проверяют fixed wire body, запрещённые
redirect, отсутствие HTTP внутри транзакции, scope/actor/binding/lease,
страницы/cursor/дубли/лимит, независимые dates и ручной источник, stale/error,
неизвестное значение против inactive, probe ledger/403 и безопасный receipt.
Локальная исполнительная среда недоступна; выполнение подтверждает CI,
а применимость реального подключения — отдельный scoped production probe.

## Повторная проверка собственного API 26.10.2026

Агентская проба ранее вернула provider_http_403. Без изменения подтверждённых
условий её не повторяем. Официальный каталог и раздел документации в этот день
недоступны поддерживаемому web-инструменту; поиск по официальному домену не дал
публичного контракта собственного read-only метода подписки услуг. Отсутствие
найденного контракта не доказывает отсутствия метода у провайдера.

Запрос, права и данные остаются отдельными фактами: агентский формат известен;
доступ текущих credentials отклонён; собственные level/isActive/expiredTo не
получены. Подходящий метод для собственного аккаунта не подтверждён.
В UI подготовлен короткий вопрос поддержке о методе и минимальных правах.
Вопрос не отправлен. Ручная дата/источник/время не изменены, 403 не превращается
в неактивный или закончившийся тариф.
