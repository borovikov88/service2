# Контекст проекта service2

Дата первичной сверки: **5 сентября 2026 года**.

## Назначение

`service2` — существующее внутреннее Django-приложение ООО «Аквалайн». Код
поддерживает обслуживание бассейнов, CRM, задачи и финансовый раздел. Финансовые
данные включают внутренние операции и импортированные данные 1С; это разные
источники, которые нельзя автоматически считать взаимозаменяемыми.

## Принципы финансовой работы

1. Прибыль, движение денег и начисление зарплаты — разные показатели.
2. В аналитике явно указываются период, организация, фильтры, источник и момент
   последнего обновления. Отсутствующее значение не заменяется нулём.
3. Исходные операции или значения импорта не удаляются ради упрощения отчёта.
   Активные версии 1С выбираются штатными query/service-функциями.
4. Любые выводы о реальных суммах допустимы только после чтения отчёта из
   выбранной рабочей организации. Фикстуры, миграции и тестовая SQLite-база не
   являются данными компании.
5. Доступ к репозиторию, к интерфейсу приложения и к рабочей базе — три разных
   вида доступа.

## Конфиденциальность

В общий репозиторий не включаются пароли, адреса приватных endpoints, выгрузки,
персональные данные сотрудников и индивидуальные зарплатные условия. Старый
пакет передачи содержал персональные сведения об оплате; они намеренно не
перенесены сюда. При необходимости они должны передаваться советнику владельцем
по отдельному защищённому каналу и только в требуемом объёме.

## Рабочий процесс

Владелец формулирует одну задачу обычными словами. Ведущий технический
руководитель определяет область и проверяемые критерии, передаёт реализацию
отдельному субагенту-разработчику, а фактический diff вместе с исходной задачей
и критериями — отдельному субагенту-проверяющему. Замечания и повторная проверка
проходят внутри технической команды без пересылки владельцем. Подробные правила
закреплены в `AGENTS.md`.

Техническая команда работает в Codex; целевая отдельная среда финансового
советника также остаётся Codex. ChatGPT не выбран как замена этой среды.
Наличие отдельных чатов само по себе не создаёт автоматического обмена
сообщениями между ними. Дословный архив прошлых разговоров в репозитории не
ведётся и этой передачей не создан.
