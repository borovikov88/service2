# Предварительный подбор основных позиций

Область: фильтрационный насос, фильтр, каждый выбранный нагреватель и четыре
роли закладных (скиммер, возвратная форсунка, слив, пылесос). Отдельная ветка
от8044e50; PR346/347 не переписываются.

## Правила

1. Сначала исключаются недоступные и противоречивые карточки, известная
   недостаточная производительность/мощность, несовпадение питания/напора,
   известное несовпадение материала/отделки/профиля. Назначение насоса для
   фильтрации с префильтром обязательно: SPA/аттракционный насос не заменяет его.
2. Отсутствующая характеристика допускает только предварительного кандидата.
   Сначала известная достаточная мощность/производительность, затем полнота
   данных, ближайший достаточный размер, затем цена внутри группы. Для1/2/3+
   сравнимых кандидатов сохранены прежние ценовые уровни трёх КП.
3. Ни расход, ни марка стали, ни напряжение не выдумываются. «Проверить» виден
   в строке; пояснение содержит конкретные пробелы, ссылку на карточку,
   дату сохранённой цены и правило ранжирования. Предупреждения повторяются
   в печати и восстанавливаются после загрузки/пересчёта.
4. Для каждого нагревателя используется полная требуемая мощность. Нагрузка
   между источниками не делится, общие работы не добавляются повторно.
5. Ручные выбор/цена/количество/исключение и прочие КП защищены. Изменённые
   технические факты того же автоматического товара обновляются при явном
   подборе, но сохранённая цена и её дата остаются прежними.
6. Если новые параметры/данные запрещают прежнюю автоматическую модель, а
   замены нет, её цена снимается из суммы с конкретной причиной. Ручная модель
   остаётся; новый конфликт выгрузки показывается отдельно без перезаписи
   сохранённых характеристик. Для фильтра учитывается max(расход чаши, насоса).

Семейство корпуса хранится отдельно от марки стали: нержавеющая сталь без
304/316 не превращается в возможный пластик. Явные запреты отделки из описания
и XML сохраняются. Марка винтов не становится маркой корпуса. Противоречивые
значения расхода/мощности в названии не превращаются в разрешённый unknown.
Новые JSON-поля optional: filtration, body_family, lining_denied в каталоге,
catalog_review_note в строке. Миграций БД нет; старые суммы при загрузке не меняются.

## Проверенные синтетические примеры

- Насос100 + фильтр200 с неизвестным расходом:300 в каждом КП с предупреждениями.
  Насос SPA, слишком слабый, с другим питанием/напором не выбирается.
- Известный достаточный8м³/ч предпочтительнее дешёвого unknown и гигантского80.
- Три нагревателя100+200+300:600; требование20кВт для каждого; unknown у первого
  отмечен, известный10кВт исключён. Работы не задвоены.
- Ручной фильтр: сохранено20м³/ч, текущий каталог10, насос12 — появляется
  предупреждение, ручная цена и сохранённые характеристики остаются прежними.
- Тот же SKU с новой ценой999 после прежней100: при подборе цена остаётся100.
- Изменения параметров/конфликты очищают только неподходящий untouched auto;
  повторный подбор не создаёт дубли, JSON/evaluate сохраняют суммы и предупреждения.

## Что останется пустым / вопросы на утро

- Нет подтверждённой категории, назначения фильтрационного насоса либо есть
  известное несоответствие/конфликт, а допустимых альтернатив нет.
- Несколько насосов без гидравлической схемы: автоматический выбор фильтра
  не предполагает параллельное или последовательное подключение.
- Форсунка регулятора уровня: отдельная логика подтверждённых пар пока сохранена;
  неизвестная схема соединения требует следующего отдельного этапа.
- Обеззараживание treatment и обвязка/автоматика piping: нужен метод/состав
  комплекта. Отдельный случайный товар не равен комплекту.
- Геотекстиль и материалы штукатурки: нет подтверждённой единицы продажи/
  упаковки и преобразования м³ в расход сухой смеси. Цену нельзя переносить
  без этих данных. Плёнка продолжает подбираться только с проверенной площадью рулона.
- Рабочие кривые, режимы нагрева, безопасность всасывания, давление/подключения
  остаются инженерной проверкой; новый алгоритм не объявляет их подтверждёнными.

Аудит и примеры относятся к коду и синтетическим карточкам. HTTP403 рабочей
выгрузки не обходился; статистика фактической заполненности production не заявляется.
