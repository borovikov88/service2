# Ручная сверка содержимого существующих объявлений услуг

Рабочий лист находится на странице существующего источника услуг, в раскрываемом
разделе «Ручная сверка содержимого карточек». Он строится из feed.published,
а не из текущего черновика: несохранённая или ещё не опубликованная правка
не подменяет ожидаемое содержимое уже выданного файла.

Источник ожидаемых значений — номер редакции опубликованного XML и, если
привязка существует, PK и время записи публикации. Время формирования листа
не является временем публикации или наблюдения карточки.

Для каждого AvitoId:
1. До проверки сохранить вид существующей карточки, её адрес, источник
   (кабинет владельца или публичная страница) и время.
2. После завершённой загрузки открыть то же объявление, сравнить Title,
   Description, фотографии, обложку и порядок с опубликованным снимком.
3. Зафиксировать фактические значения, отличия, адрес источника, время и автора
   ручной проверки. Невидимое поле оставить неизвестным.
4. Сохранить заполненный лист/снимки в разрешённом рабочем хранилище компании,
   не в Git и не в публичных логах.

Лист не выполняет запросов к URL фотографий, не содержит формы сохранения
заключения и не устанавливает content_verified. Выбранные методы API не
возвращают достаточные фактические поля карточки; активность объявления,
совпадение Id/AvitoId и успешная загрузка XML не заменяют эту сверку.
Подтверждённое получение входного файла также не доказывает содержимое карточки.
