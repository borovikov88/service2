# Подробный отчёт автозагрузки Avito v4

Источник контракта: копия OpenAPI официального каталога от 03.10.2026,
https://github.com/MissiaL/avito-api/blob/main/references/avito-api-openapi.json,
Git blob 3c393220f1112550dba69d450cd9cfa6e40cf816.
Происхождение и ограничения копии описаны в references/sources.md этого
репозитория. Официальные HTML/JSON URL каталога недоступны текущему инструменту;
копия не доказывает свежий ответ API или доступ конкретных сохранённых ключей.
В код перенесены только необходимые поля/структуры, без полного спека.

Методы GET:
- /autoload/v4/uploads/current и /current/items;
- /autoload/v4/uploads/last_successful и /last_successful/items.

Состояние last_successful означает завершённую обработку и может включать
success_warning с ошибками отдельных объявлений. Current может оставаться
processing; такой отчёт явно предварительный. API v4 даёт детали лишь текущей
и последней обработанной загрузки, не произвольного старого report_id.
Для отчёта со скриншота №613469185 сначала надо проверить фактический upload_id.
Миграционный текст копии указывает прекращение старых v2/v3 report методов
08.03.2027 и неполные исторические сведения старше семи дней с 08.09.2026.

Явный CSRF POST выбранного подключения использует существующие credentials,
проверяет профиль, организацию и lease; при изменении подключения старый результат
не сохраняется. GET интерфейса и CSV читают сохранённый снимок. Новое чтение
не включено в basic refresh или расписание: текущая версия ручная.

Обход: perPage=50, строгая пагинация/ожидаемая длина, до 5000 строк и 55 секунд
плюс последний HTTP timeout существующего клиента (8 секунд). Shared DB throttle
account+autoload_report не чаще одного запроса в три секунды, bounded wait.
Summary до/после должна совпасть: смена alias или счётчиков отменяет снимок.
Это не атомарная транзакция провайдера; processing остаётся предварительным.
API list total и processed stats.count не подменяют друг друга.

Сохраняются allowlisted поля: XML ID, ID/статус Авито, раздел и сообщения с
типом/кодом/текстом/временем. Archive и removed различаются по контракту Autoload;
не меняются статусы/уведомления существующего Item API монитора.
Тексты до 3000 символов с отметкой усечения, контакты/URLs/credential patterns
скрываются, полный report до 2 MiB. Копии фида и их signed URLs не сохраняются.
Неполный обход/отказ не превращается в успешный ноль; предыдущий snapshot и
success_at сохраняются как stale.

CSV содержит все сохранённые строки/сообщения и глобальные события, UTF-8 BOM,
состояние загрузки и время снимка; отдельный scoped GET, no-store/nosniff,
защита ячеек от spreadsheet formula injection. На экране до 200 строк.
Не выполняются upload, запуск автозагрузки, правки профиля/категорий/товаров,
смена XML ID, снятие объявлений или платные действия.
