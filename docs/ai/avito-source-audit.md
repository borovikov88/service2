# Проверка XML магазина

Сервис проверяет уже названный владельцем публичный источник
https://shop.aqualine22.ru/avito/avitofeed.xml и stock-only GET
/index.php?route=extension/module/avitofeed&stock. Код stock-only ветки в
shop.aqualine22.ru main bfeb0f2708a0eb3079eda7507e75cf030e4ec336 подтверждает,
что она не вызывает toFile: data_file остаётся пустым. Обычный маршрут
генерации XML не вызывается.

В разделе подготовки к аудиту кнопка «Проверить XML магазина» выполняет
явный CSRF POST с существующей проверкой прав управления каналом и организации,
lease и проверкой подключения перед сохранением. GET страницы читает снимок.
Проверка XML не требует ключей Авито, не входит в общее обновление и
не подтверждает связь источника с выбранным аккаунтом Авито.

Отчёт сохраняет счётчики и до 25 безопасных XML ID/названий полей с проблемами,
без полного XML, контактных данных и секретов. Повторяющиеся XML ID — проблема
источника; они не доказывают дубли активных объявлений на Авито.
Пустой TNVEDCode считается отдельно без вывода об обязательности в категории.
Остатки плагина сопоставляются по XML ID: повторяющиеся/некорректные строки и
отсутствующие ID остаются неизвестными. Количество магазина не считается
подтверждением физического склада или активности объявления на Авито.

Читаются только два фиксированных HTTPS пути, без прокси и redirects.
DNS адреса должны быть публичными; соединение закреплено за проверенным IP,
TLS проверяет исходный hostname. Каждый ответ ограничен 2 MiB, 5000 строками
и HTTP бюджетом 20 секунд; системное DNS-разрешение отдельно зависит от
настроек resolver хостинга. XML допускает UTF-8, запрещает DTD/entities и
проверяет структуру. Ошибки не превращают неизвестный результат в ноль:
старый успешный снимок сохраняется со своим временем и stale-состоянием.
Ошибка остатков не отменяет завершённую проверку XML, но явно отображается.

Никаких изменений товаров, правил, XML ID, публикации или продвижения нет.
Настройки трёх правил из production OpenCart DB и подробные причины ошибок
автозагрузки этим отчётом ещё не проверяются. Анализ заполнения полей не
называется оценкой позиции в поиске. Автоисправление требует подтверждённой
ошибки, связи с товаром и защищённого канала записи в источник.
