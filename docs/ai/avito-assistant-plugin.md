# Закрытый плагин чтения Авито Услуг

Исходник пакета: `tools/avito-assistant-plugin/service2-avito-services-read/`.
Это подключение к уже существующему серверу, а не новый MCP backend или сборщик.
Ресурс и транспорт подтверждены текущим кодом: HTTPS `/mcp/avito`, Streamable HTTP.
Auth metadata поддерживают OAuth authorization code + PKCE S256 и CIMD;
пакет использует только ресурсный scope `service2.avito.read`.

Внутри только portable `plugin.json`, `mcp.json` и существующая эмблема Аквалайн.
Нет токенов, client secrets, предоставленного client ID, cookies, app bindings,
настроек Finance/1C или расширения серверных полномочий. Поддержка CIMD не
означает, что конкретный клиент уже одобрен для организации.

Пакет сохраняется как PRIVATE через штатный Plugin Creator. Создание записи
плагина, установка, завершение OAuth и доступность инструментов в чате — разные
факты. Если OAuth или штатная регистрация principal блокируют подключение,
владелец завершает защищённый процесс; grants не создаются миграцией, deploy
или подменой другого подключения. Finance/1C токены не используются.

Ожидаются ровно существующие инструменты `get_avito_funds`,
`get_avito_listings`, `get_avito_upload_report`, `get_avito_statistics` и
`get_avito_diagnostics`. Настоящая tools/list и безопасный read требуют отдельного
подтверждения после установки и согласия. Источником перечня до этого остаются
проверяемые `avito_mcp_views` / `avito_mcp_reader`, а не заявленная живая discovery.

При проверке подключения использовать connection_id=4. Проверить совпадение
аккаунта446312402, источник, время получения/чтения и полноту; неизвестные поля
не превращать в0. Отдельно подтвердить отказ для connection_id=1. Реальная
проверка не требует обновления провайдера, сообщений, публикации XML или платежей.

Упаковка: один каталог с именем из manifest, архив вне него. Перед загрузкой
проверить JSON, совпадение имени, SemVer, длину shortDescription≤30, включённую
эмблему и точный список трёх файлов. Архив не включается в Git; воспроизводится
из этих исходников. Публичная публикация и изменение аудитории не выполняются.
