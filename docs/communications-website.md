# Канал «Сайт» в разделе «Коммуникации»

## Подключение

Основной путь настройки — интерфейс владельца Service2:

1. Откройте **Коммуникации → Каналы связи → Сайт → Добавить**.
2. Укажите название и внутренний идентификатор сайта.
3. После создания сохраните однократно показанный bearer-токен. Service2 хранит
   только его хеш; повторно посмотреть токен нельзя.
4. `public_id` и готовые API-пути остаются доступны на странице настроек
   подключения. Токен храните только в защищённой конфигурации backend сайта,
   не помещайте его в Git или клиентский JavaScript.

Серверная команда `rotate_communication_token CONNECTION_ID` остаётся
аварийным/служебным способом ротации, но для обычной настройки не требуется.

Все запросы передают заголовок `Authorization: Bearer TOKEN`, используют JSON и
адреса с `public_id` конкретного подключения.

## Онлайн-чат

- `POST /api/communications/website/{public_id}/chat/messages/` принимает
  `session_id`, уникальный `message_id`, `name`, необязательный `phone` и `body`.
- `GET /api/communications/website/{public_id}/chat/{session_id}/outbox/?after=ID`
  возвращает до 100 ответов менеджеров после указанного ID.
- `POST .../outbox/ack/` с `{"message_ids": [1, 2]}` подтверждает доставку.
- Файлы исходящих сообщений возвращаются в `attachments`. Скачивать их следует
  backend-запросом с тем же bearer-токеном.

Повтор `message_id` идемпотентен и не создаёт второе сообщение.

Outbox использует доставку «как минимум один раз»: до ACK одно сообщение может
быть возвращено повторно, например если ответ предыдущего GET потерян. Backend
сайта обязан дедуплицировать ответы по целочисленному `id`, показать сообщение
посетителю и только затем отправить ACK. Подтверждённые и ошибочные сообщения
больше не возвращаются outbox; ACK не может перевести `failed` в `delivered`.

## Форма заявки

`POST /api/communications/website/{public_id}/requests/` принимает уникальный
`request_id`, `name`, `phone`, а также необязательные `service`, `delivery`,
`address` и `comment`. Повтор `request_id` возвращает существующую заявку.

Тело запроса ограничено 64 КиБ. API не принимает секреты клиента, cookies
Service2 или произвольные идентификаторы организации: организация определяется
только по аутентифицированному подключению.
