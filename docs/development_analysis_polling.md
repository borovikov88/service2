# Фоновая проверка AI-анализа

Команда безопасно и идемпотентно проверяет незавершённые анализы:

```bash
python manage.py poll_development_analyses --batch-size 50
python manage.py poll_development_codex --batch-size 25
```

Для production её следует запускать cron/scheduler примерно раз в минуту. Чтобы не
накладывать процессы на уровне ОС, можно использовать `flock`; идемпотентность при
этом всё равно обеспечивается приложением и уникальными ключами уведомлений.

Временная ошибка OpenAI оставляет анализ активным для следующего запуска. Вывод и
логи содержат только счётчики, ID итерации и тип ошибки, но не ответы и секреты.
