# Локальный запуск

Эта инструкция предназначена только для локальной разработки. Не используйте
учётные данные, адрес или имя продакшен-базы Beget.

## Требования

- Python версии, совместимой с `requirements.txt`;
- отдельный локальный экземпляр MySQL;
- отдельная пустая база и пользователь MySQL только для разработки.

## Подготовка окружения

В PowerShell из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните новый `.env` локальными значениями. Не копируйте `.env` с сервера или
из старой версии проекта. Обязательные параметры подключения:

```dotenv
DB_ENGINE=django.db.backends.mysql
DB_NAME=
DB_USER=
DB_PASSWORD=
DB_HOST=127.0.0.1
DB_PORT=3306
```

Также задайте новый локальный `SECRET_KEY`. Перед любой Django-командой,
обращающейся к базе, отдельно проверьте, что `DB_HOST` указывает на локальный
MySQL, а `DB_NAME` — на специально созданную базу разработки.

## Создание схемы и запуск

Миграции допустимо применять только к проверенной локальной базе:

```powershell
python manage.py migrate
python manage.py runserver
```

Не запускайте эти команды с продакшен-переменными. Локальные базы, дампы,
резервные копии, `.env`, `media/` и `private_media/` не должны добавляться в Git.
