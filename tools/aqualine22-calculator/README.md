# Калькулятор водоочистки на aqualine22.ru

Статическая страница `/kalkulyator-vody/` подбирает предварительную схему по анализу воды и параметрам дома. Ввод остаётся в браузере. Точный подбор и безопасность воды требуют лабораторного анализа и специалиста.

Этот каталог хранит только калькулятор. Исходники WordPress информационного сайта, настройки CMS, база данных и файлы магазина сюда не импортируются. Публикация использует существующую защищённую SSH-конфигурацию Environment `production`; закрытый ключ не покидает runner и не записывается в Git.

Workflow `Test and deploy main` проверяет расчёты, границы публикации и полный набор тестов Django. Его test-job сначала ожидает определение состава изменений и передаёт результат публикации только после успеха всех проверок. SSH-публикация разрешена только из точного актуального `main` через Environment `production`. Для изменений только калькулятора и связанной CI-конфигурации Service2 не обновляется; смешанные изменения сохраняют прежний путь Service2. Ручное восстановление Service2 не изменено. Неизвестный или пустой diff останавливает публикацию.

SSH-шаг ищет единственный обычный WordPress-каталог в домашнем каталоге владельца с точным SHA-256 публичного логотипа действующего aqualine22.ru. Каталоги магазина, Service2, staging и резервные каталоги исключены. Отсутствие или несколько совпадений останавливают публикацию до записи файлов. Затем создаётся временный случайный проверочный файл и читается через фиксированный HTTPS-домен без редиректов: только точное совпадение подтверждает фактическую привязку webroot к aqualine22.ru. Проверочный файл удаляется при успехе или ошибке.

Публикуется только папка `kalkulyator-vody`. Проверяются состав архива и хеш каждого файла. Неизвестная существующая страница и местные изменения сохраняются: операция останавливается. Для обновления собственной неизменённой страницы сохраняется закрытая копия вне `public_html`; при ошибке переключения восстанавливается прежняя папка. Файлы CMS и её база данных не изменяются. После успешной записи проверяются публичная страница и расчёт в браузере; успешный SSH-шаг сам по себе не доказывает доступность страницы.

В `deploy.json` можно временно выбрать `mode: inspect` для проверки без записи. Домен и каталог страницы фиксированы в коде. Публичный логотип: `https://aqualine22.ru/wp-content/uploads/2013/05/logo5.png`.

Проверки: `node --test tools/aqualine22-calculator/tests/engine.test.mjs` и `python3 -m unittest discover -s .github/tests -p test_aqualine22_publication.py -v`.
