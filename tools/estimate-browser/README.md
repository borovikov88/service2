# Локальная браузерная регрессия смет

Сервер использует настоящие шаблон, JS и функции расчёта, но только синтетическое
состояние в памяти. Рабочая БД, каталог и production не используются.

1. Из окружения с зависимостями Django запустить `python tools/estimate-browser/server.py`.
2. В другом терминале с установленным Playwright запустить
   `node tools/estimate-browser/regression.cjs`.

Нужен Chromium в `/usr/bin/chromium`; сервер слушает только127.0.0.1:8769.
При внешней установке Node-модулей можно передать `NODE_PATH`.
Сценарий проверяет три типа нагрева, исключение/восстановление пары аксессуаров,
отвязку → сохранение → повторное открытие → привязку → сохранение без ввода
количества, отсутствие дублей и ручной ноль (включая серверный ответ).
Также проверяет неизвестную штукатурку в новой смете и сброс строительного объёма.
Это UI-регрессия; авторизация/изоляция и сохранение версий покрываются Django-тестами.
