Данные Service2 для МегаФона

Это второе направление интеграции: АТС МегаФона → Service2.
Назад
Скопируйте ключ сейчас. Service2 хранит только его хеш и не сможет показать этот ключ повторно. Повторное подключение создаст новый ключ и немедленно отключит старый.

Что вставить в редактируемые поля МегаФона

  1. Откройте Настройки → Интеграция с CRM → Ваша CRM / REST API.
  2. В поле Имя вашей CRM укажите Service2.
  3. В поле Адрес вашей CRM вставьте URL выше.
  4. В поле Ключ для авторизации в вашей CRM вставьте ключ выше.
  5. Для всех номеров оставьте включёнными как минимум команды history, event и contact.
  6. Сохраните настройку и сделайте один тестовый входящий и один исходящий звонок.
Важно: неизменяемые поля МегаФона «Адрес АТС» и «Ключ для авторизации в АТС» идут в противоположную сторону — их нужно скопировать из кабинета МегаФона в Service2 через «Адрес и ключ АТС». Эта страница показывает только данные, которые нужно вставить обратно в редактируемые поля «Адрес вашей CRM» и «Ключ для авторизации в вашей CRM».
После сохранения вернитесь в «Коммуникации → Каналы связи» и нажмите «Проверить API». Service2 запросит у ВАТС список сотрудников командой accounts. Затем сделайте тестовый звонок: у линии появится live-событие, а после завершения — история звонка во вкладке «Звонки».
