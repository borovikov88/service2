Связь версии с загрузкой Авито

Запись истории № {{ publication.version.pk }} · опубликована {{ publication.version.created_at }}.

При выборе этого адреса в кабинете Авито фиксируется весь снимок объявлений этой версии. Следующая публикация в Service2 не изменит его содержимое: для новой версии потребуется снова согласовать и заменить источник в Авито. Не переключайте источник до проверки текущей ревизии, состава и точных HTTP-байтов.

Неизменяемый адрес позволяет подтвердить версию, если API отчёта возвращает его напрямую. Старый адрес продолжит отдавать прежнюю версию. Для постоянного feed.xml автоматический читатель может проверить входную XML-копию Авито: полный набор Id/AvitoId и точный SHA-256 должны совпасть с одной версией, опубликованной до начала загрузки. Настройки Авито автоматически не меняются. До ручного изменения источника нужно проверить доступность и точные байты этого адреса; совпадение нашего HTTP-ответа не означает получение файла Авито.

Адрес копии Авито сам по себе не доказывает ошибку настройки. Без подтверждённой XML-копии дата и совпадение Id дают лишь кандидатную связь. Если Авито отдаёт только защищённый адрес копии (например, HTTP 401), неизменяемый адрес сам по себе не снимает это ограничение. Копия XLSX или другого неподдержанного формата, недоступная копия и одинаковые байты нескольких версий без точного неизменяемого URL оставляют точную публикацию неподтверждённой. Старый отчёт новую публикацию не подтверждает.
