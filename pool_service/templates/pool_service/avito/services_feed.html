Связь версии с загрузкой Авито

Для точной связи источника настройте в кабинете автозагрузки этого аккаунта этот адрес версии. При следующей публикации появится новый адрес. Старый адрес продолжит отдавать прежнюю версию. Service2 не меняет настройки Авито автоматически. Точная связь появится только если API отчёта вернёт этот же адрес; если Авито указывает адрес своей копии файла, источник версии остаётся неподтверждённым.

Другой адрес в API отчёта может быть копией файла на стороне Авито и сам по себе не доказывает неверную настройку. Если в Авито остаётся постоянный адрес feed.xml, последующая загрузка с теми же Id сопоставляется лишь как кандидат: дата и совпадение Id не доказывают точную версию файла. Старый отчёт новую публикацию не подтверждает.
